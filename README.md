## README (quick)

### Requirements
- Flutter SDK (stable channel). Use `flutter --version` to check.
- `dart` 3.x compatible.

### Setup
```bash
# get dependencies
flutter pub get

# generate code
flutter pub run build_runner build --delete-conflicting-outputs

# run app
flutter run

# run tests
flutter test
```

## 📦 Packages Overview (Installed + Descriptions)
Below is a full description of all packages included in this starter project. This expands the README to explain **why each package is used**, what problem it solves, and when to extend it.

### ### **Core Framework & Architecture**

#### **flutter_riverpod**
A modern, compile‑safe state management library.
- Zero boilerplate compared to Provider.
- Great for asynchronous logic, repositories, and dependency injection.
- Scales well for medium/large apps.

#### **go_router**
Officially recommended Flutter router system.
- Declarative routes, deep linking, URL sync.
- Simpler and cleaner compared to Navigator 2.0 boilerplate.

---

### ### **Code Generation / Models / Types**

#### **freezed_annotation + freezed**
Used to generate immutable data models.
- Adds `copyWith`, equality, unions/sealed classes.
- Essential for clean architectures.

#### **json_serializable** *(included automatically via Freezed)*
Handles JSON parsing for models generated by Freezed.

---

### ### **Database / Persistence**

#### **drift + drift_dev**
Advanced SQLite ORM for Flutter.
- Strong typing, migrations, DAOs.
- Perfect for offline‑first apps.
- Much more scalable than Hive for complex relations.

#### **path_provider**
Used by Drift to locate local file directories.

#### **flutter_secure_storage**
Stores sensitive data like:
- PIN hashes
- Auth tokens
- Encryption keys

Uses platform‑level secure APIs (Keychain/Keystore).

---

### ### **Device Features & Integrations**

#### **local_auth**
Biometric authentication.
- Face ID, Touch ID, fingerprint.
- Used for secure app unlock.

#### **flutter_local_notifications**
Displays notifications on iOS/Android.
- Used for reminders, recurring transactions, and goal updates.

#### **workmanager**
Schedules background tasks.
- Runs recurring transaction jobs.
- Cross‑platform.

---

### ### **Charts / UI Enhancements**

#### **fl_chart**
Modern Flutter chart library.
- Used to show spending charts, goal progress.

#### **lottie**
Adds animated vector assets.
- Great for empty states, onboarding, success animations.

#### **intl**
For formatting:
- Currency
- Dates
- Numbers

Required in financial apps.

---

### ### **Development Tools**

#### **build_runner**
The engine that generates code for:
- Freezed models
- Drift tables
- JSON serialization

#### **mocktail**
A mock library for Dart.
- Used for repository and unit tests.
- Cleaner API than Mockito.

#### **flutter_test**
Default Flutter testing library.
- Widget tests
- Unit tests
- Golden tests
